# Toolnex — AdSense 整改补强包

本包针对 Google AdSense 驳回原因 **"低价值内容（Low value content）"** 进行了定向整改。
策略：**保留你原有的 18 个原创游戏（无 iframe、无搬运，是真实资产），补上 AdSense 真正要的"内容层" + 重写为站点专属的真实信任页。**

---

## 一、为什么之前没过（诊断）

1. **主体价值是"游戏"而非"文字内容"** — AdSense 审核员不把互动游戏算作"内容"，要的是原创编辑性文字（攻略/教程/博客）。
2. **正文太薄** — 每个游戏页几乎只有一句话描述，可读文字极少。
3. **信任页是通用模板** — About / Privacy / Terms 像套版生成，审核可识别，反而印证"无独特价值"。
4. **没有博客/攻略/长文** — 缺少持续产出的原创内容，这是"低价值内容"最直接的证据。

## 二、本包做了什么

- **重写 5 个信任页**（about / privacy / terms / contact / cookie-policy）为站点专属、具体、有真人感的内容（含真实数据说明、GDPR/CCPA 权利、具体 cookie 表）。
- **重构首页** 为"编辑型门户"：攻略/内容前置，游戏作为互动特色，含精选文章区、清晰导航与页脚内链。
- **新增博客（blog/）**：1 个博客首页 + **8 篇具体、实用、引用了你站点真实游戏名的原创长文**，证明内容是站点原生、非搬运生成。
- **新增 sitemap.xml 与 robots.txt**，帮助审核爬虫理解站点结构。

## 三、如何上传（保留游戏，只覆盖/新增以下文件）

通过你的主机面板（cPanel / FTP / 对象存储）把本包内容上传到网站根目录 `public_html`（或你的 web root）：

**覆盖（同名替换，会更新现有页）：**
- `index.html`
- `about.html`
- `privacy.html`
- `terms.html`
- `contact.html`
- `cookie-policy.html`

**新增（直接上传，不要覆盖任何现有文件）：**
- `blog/` 整个目录（含 `index.html` 与 8 篇文章）
- `sitemap.xml`
- `robots.txt`

**务必保留、不要动：**
- `games.html` 及全部 18 个游戏页（`2048-challenge.html`、`neon-runner.html` 等）——它们是原创游戏，保留即可。
- 建议同时核对 `games.html` 顶部导航是否也加上 "Guides" 链接（指向 `blog/index.html`），保持全站一致。

> 注意：本包里的 `index.html` 已链接到 `blog/`，而现有 `games.html` 仍在服务器上，二者共存即可，无需改动游戏页。

- [ ] 建议在提交前让站点"跑" 1–2 周：有真实访问、博客可继续补 2–3 篇，信号更稳。
- [ ] 回到 AdSense 后台 → 该站点 → 勾选"我确认已解决相关问题" → 申请审核。

## 五、诚实提示（重要）

- **没有任何人能保证 100% 通过。** "纯游戏/工具聚合站"是 AdSense 最难过的类别之一。本整改大幅提升了"有独特编辑价值"的证据，但审核是人工+算法综合判定。
- **继续加码最有效：** 后续每多一篇真实、具体的攻略/评测长文，通过概率就更高。建议把"每款游戏一篇 600+ 字原创攻略"作为下一步目标。
- **避免 AI 痕迹：** 本包文案已尽量具体、引用真实游戏名；若你用 AI 继续扩写，请人工润色，避免大段雷同模板句（那本身也会触发"低价值/自动生成内容"）。
- **流量/站龄：** 全新站即使内容好也可能被要求"再积累"。保持更新、积累自然访问，是最稳的加分项。
